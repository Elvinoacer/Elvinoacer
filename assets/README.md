# Calm GitHub Telemetry Assets

All SVGs in this folder are pure-vector, gently animated, light/dark adaptive visuals generated automatically every 6 hours by [`.github/workflows/update-profile.yml`](../.github/workflows/update-profile.yml) via [`scripts/update_profile.py`](../scripts/update_profile.py) directly from the GitHub GraphQL API:

- **`hero-{light,dark}.svg`**: Serene highland mist header with drifting mist, breathing celestial glow, floating light motes, and live streak telemetry.
- **`stats-overview-{light,dark}.svg`**: Circular ring gauges (Rank & Lifetime Impact, Annual Consistency, Current & Best Streak), 6 icon-led metric tiles (Commits, Merged PRs, Private activity, Public Repos, Stars/Forks, Followers/Starred), and 3-column Yearly Momentum cards.
- **`stats-rhythm-{light,dark}.svg`**: Language donut chart across all public non-fork repositories, core stack pills, weekly cadence bars, and East Africa Time (`EAT · UTC+3`) coding rhythm.
- **`activity-flow-{light,dark}.svg`**: *Calm Currents* — softly rolling infinite silk-water waves, 12 luminous monthly contribution orbs, expanding zen water ripples, drifting fireflies, and a full 52-week calm activity ribbon.
