# Calm GitHub Telemetry Assets

All SVGs in this folder are pure-vector, light/dark adaptive charts generated automatically every 6 hours by [`.github/workflows/update-profile.yml`](../.github/workflows/update-profile.yml) via [`scripts/update_profile.py`](../scripts/update_profile.py) directly from the GitHub GraphQL API:

- **`hero-{light,dark}.svg`**: Serene highland mist identity banner with live streak and contribution telemetry.
- **`stats-overview-{light,dark}.svg`**: All-time & rolling 365-day totals, commits, PRs, reviews, stars, forks, streaks, active days, best day, and yearly growth trajectory.
- **`stats-rhythm-{light,dark}.svg`**: Byte-weighted language composition across all public non-fork repositories, weekly cadence (Mon–Sun), and East Africa Time (UTC+3) coding rhythm.
- **`activity-horizon-{light,dark}.svg`**: *The Quiet Horizon* — a layered mountain & still-lake reflection panorama sculpted directly from real 52-week and 30-day GitHub contribution data, paired with a 26-week calm mosaic.
