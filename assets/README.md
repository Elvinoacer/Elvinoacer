# Deep-Space 3D Profile Artwork

All profile visuals are procedurally generated by [`scripts/render_assets.py`](../scripts/render_assets.py) using 3D perspective projection, gravitational potential well equations, and 60fps SVG animations:

- **`hero-3d.svg`**: Relativistic Black Hole (Gargantua-style gravitational lensing, Doppler-shifted accretion disk, curved 3D spacetime funnel, and 4-wave warp-drive star streaks).
- **`card-01.svg` – `card-06.svg`**: 6 custom 3D holographic space cards, each with a unique 3D rotating wireframe hologram (double helix, geodesic sphere, nested tesseract, 3-axis gyroscope, architectural prism tower, hexagonal bipyramid crystal) and large metric blocks.
- **`architecture-3d.svg`**: 3D tilted elliptical solar system with orbiting stack satellites.
- **`footer.svg`**: Planetary atmospheric limb horizon from orbit.
